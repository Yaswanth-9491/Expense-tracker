# 💰 Expense Tracker

A modern and responsive Expense Tracker built using **React**, **React Router**, and **localStorage**.

Track your daily expenses, view spending statistics, and manage your finances efficiently.

---

## ✨ Features

✅ Add Expenses

✅ Delete Expenses

✅ View Total Expenses

✅ Category-wise Statistics

✅ Persistent Data Storage using localStorage

✅ Multi-Page Navigation with React Router

✅ Responsive User Interface

---

## 🚀 Tech Stack

| Technology | Purpose |
|------------|---------|
| React | Frontend Framework |
| React Router DOM | Navigation |
| JavaScript (ES6+) | Logic |
| CSS | Styling |
| localStorage | Data Persistence |
| Vite | Development Environment |

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project:

```bash
cd expense-tracker
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```
